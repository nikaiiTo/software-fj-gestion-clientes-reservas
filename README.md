# Software FJ – Sistema de Gestión de Clientes, Servicios y Reservas

## Descripción
Aplicación desarrollada en Python mediante programación orientada a objetos para gestionar clientes, servicios y reservas de la empresa Software FJ.

## Objetivo
Implementar un sistema que permita registrar clientes, administrar servicios y procesar reservas, aplicando principios de programación orientada a objetos y manejo de excepciones.

## Tecnologías utilizadas
- Python 3.
- GitHub.
- GitHub Codespaces.

## Estructura del proyecto
- `main.py`: ejecución principal y simulación de operaciones.
- `entidades.py`: clases Entidad y Cliente.
- `servicios.py`: servicios de salas, equipos y asesorías.
- `reservas.py`: gestión y procesamiento de reservas.
- `excepciones.py`: excepciones personalizadas.
- `logs.txt`: registro de eventos y errores generados durante la ejecución.

## Ejecución
Desde la terminal, ejecutar:

```bash
python main.py
```

## Características
- Programación orientada a objetos.
- Abstracción, herencia, encapsulamiento y polimorfismo.
- Validación de clientes y servicios.
- Gestión de reservas.
- Excepciones personalizadas.
- Registro de eventos y errores.
- Simulación de operaciones exitosas y fallidas.
